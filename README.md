# HUD VCS — ativação

Arquivos usados pelo app HUD VCS para ativar a versão completa com o código curto de cada compra.

Cada arquivo em `k/` é uma chave de ativação **cifrada**: o nome e o conteúdo só fazem sentido com o código que o comprador recebeu. Sem o código, não dá para ler nem saber de quem é.
